UPDATING THE METRIC VALUES (ONGOING)
--------------------------------------
To update metric values at any time:
1. Go to WP Admin > Impact Bar Settings
2. Edit any field (numbers, labels, descriptions, button)
3. Click "Update" to save
4. Clear caches if needed
5. Changes will be visible immediately on all pages

No code editing required — everything is managed from the admin.


ACF FIELDS REFERENCE
---------------------
Field Name                  | Type      | Description
----------------------------|-----------|----------------------------------
impact_bar_title            | Text      | Section heading ("Our Impact")
impact_bar_metrics          | Repeater  | 1-6 metrics, each with:
  > metric_number           | Text      |   Number inside circle
  > metric_label            | Text      |   Bold label below circle
  > metric_description      | Textarea  |   Description below label
impact_bar_button_text      | Text      | CTA button text
impact_bar_button_link      | URL       | CTA button link

All fields fall back to hardcoded defaults if empty.


ADDING IMPACT BAR TO OTHER PAGES
----------------------------------
The Impact Bar can be included on any template with:
  <?php get_template_part('template-parts/impact-bar'); ?>


ADDING FUTURE CSS CHANGES
---------------------------
All new custom CSS should be added to:
  /wp-content/themes/twentyseventeen-child/css/custom.css

This file is enqueued with time() version so changes are
always visible immediately without manual cache-busting.
Do NOT add new CSS to style.css — use custom.css instead.


ROLLBACK PLAN
--------------
If something goes wrong:
1. Replace footer.php with the backup from Step 1
2. Replace functions.php with the backup from Step 1
3. Delete css/custom.css from the server (optional)
4. Delete template-parts/impact-bar.php from the server (optional)
5. Clear all caches
6. The site will be restored to its previous state
